This is a small publication about building software. No growth hacks, no thought leadership, no ten-slide carousel explaining what an API is.

Everything here comes out of actual work: things that broke in production, decisions that looked smart in the planning doc and stupid three months later, tools that earned their place and tools that did not. If a post says a technique works, it is because it worked on something real, not because it read well.

The site itself is deliberately boring technology. Django on the back, server-rendered HTML on the front, SQLite underneath. No client-side framework, no build step, no hydration. It loads fast because there is almost nothing to load.

The look is borrowed from print — a serif you can read for twenty minutes, generous margins, real hierarchy, and grain on the paper. Screens have spent fifteen years imitating apps. Reading is still better on a page.

Comments are open on every post and go straight up, unmoderated, because moderating a blog nobody has found yet is a strange use of an evening.

Want to publish here? The desk is open — hit Write and file something.
